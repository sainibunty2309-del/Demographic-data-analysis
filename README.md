# Demographic Data Analyzer

A data analysis project built using Python and Pandas as part of the freeCodeCamp Data Analysis with Python Certification.

## Project Overview

This project analyzes demographic and income-related data extracted from the 1994 U.S. Census database.  
The goal is to perform data analysis and answer important statistical questions using Pandas.

## Features

- Race-wise population analysis
- Average age calculation
- Education-based income comparison
- Salary distribution analysis
- Country-wise earning percentage analysis
- Occupation analysis for high-income individuals

## Technologies Used

- Python
- Pandas

## Dataset Information

The dataset contains demographic details such as:
- Age
- Education
- Occupation
- Working hours
- Salary
- Native country
- Race and gender information

## Questions Solved

- How many people of each race are represented?
- What is the average age of men?
- What percentage of people have a Bachelor's degree?
- What percentage of people with advanced education earn more than 50K?
- What percentage of people without advanced education earn more than 50K?
- What is the minimum number of working hours per week?
- What percentage of minimum-hour workers earn more than 50K?
- Which country has the highest percentage of high-income individuals?
- What is the most popular occupation for people earning more than 50K in India?
